# Security policy

## Supported versions

This project is experimental. Security fixes are applied to the current
`main` branch only; older commits and snapshots are not supported.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues.

Report them privately through
[GitHub Security Advisories](https://github.com/AndreevMakc/deep-research/security/advisories/new).
Include a description, affected component, reproduction steps, and potential
impact. You may omit exploit details until the report is acknowledged.

The maintainer will acknowledge a report when it has been reviewed, coordinate
validation and remediation privately, and publish details after a fix or
mitigation is available.

## Scope

Reports about authentication, tenant isolation, webhook signatures, source
fetching, secret exposure, publication controls, and dependency vulnerabilities
are in scope. General product suggestions belong in GitHub Issues.
